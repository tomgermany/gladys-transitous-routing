# Transitous Departures Gladys-imut atassusernera

## Makku pisariaqartippatit:

Gladys Assistant > Version 5.2

Avammut atassusiiffik Transitous Departures

Gladys Assistant-it internetimut atassuteqassaaq

## Pissarsiatit:

Gladys Assistant-imut avammut atassusiiffimmik pissarsissaatit.
Atassusiiffiup matuma qanitsinni qatserisut/angallatit aallartussat tulliuttut 6 saqqummiutissavai widget-imi erseqqissumi – bussinit qimuttuitsunut, umiarsuarnut aqqusinernullu.
Tamanna tamatigoortumik illit angerlarsimaffippit eqqaani ujaasiffiup iluani ivertinneqarsinnaavoq.

Assersuut:

![Lissabon – Transitous-imut assersuut](../test/lissabon.png)

Inernera: Allagartat arfinit tamarmik immikkut uniffik qaninnerpaaq siullermik paasiniarneqartarpoq. Tassa bussiinnarfiup uniffia, umiarsualivik imaluunniit qimuttuitsut uniffiat qaninnerpaaq.
Uniffimmit tassannga aallarfissaq tulliuttoq saqqummiunneqassaaq.
Tassa imaappoq: Ujaasiffiup iluani uniffik ataasiinnaappat, aallarfissat tulliuttut arfinit takussavatit.
Uniffiit arlaliuppata, qalipaatit atorlugit immikkoortinneqassapput.

## Ivertitsineq

1. Avammut atassusiiffik Gladys Assistant atorlugu ivertiguk (inassutigineqarpoq)
 imaluunniit Gladys Assistant-imi GitHub-imut sassaalluni.

2. Ivertitsinerup kingorna atassusiiffik ingerlalluarnersoq misissoruk.
   
3. Dashboard-it ammaruk, aaqqissuussiffimmut (Edit Modus) iserlutit widget nutaaq ilannguguk.
   Atassusiiffiup widget-ia toqqaruk.
   
4. Widget dashboard-imut ilanngukkukku, paasissutissat makku pisariaqartissavatit:
   
a.) Sumiiffiit aallartiffittut
 (imaluunniit Gladys Assistant-imit sumiiffik toqqaruk)
 
b.) Ujaasiffiup silatussusia meterinngorlugu.

c.) Nutarteriffik minutsit 10-kkaarlugit.

d.) API sassaaffiginiarlugu kinaassuseq immikkoortoq uani https://transitous.org.
Kinaassuseq manna immikkut ittussaavoq—assersuutigalugu e-mail imaluunniit nittartagaq.
Atassusiiffiup ivertitsivimmi tassannaannaq toqqortarpaa.
Atassusiiffiup kinaassuseq manna aaneq ajorpaa imaluunniit allattorneq ajorpaa.
Tamarmik illit pigaatit. Transitous.org-ip kinaassuseq manna atorpaa IT-infrastrukturimut nammaat aqullugu.
Paasissutissanik pilersuisoq eqqarsaatigiuk ivertitsiguk. Minutsit 15 inassutigaarput.

5. Paasissutissat immersoreerlugit, toqqoruk widget-ilu sumiiffissamut kissaatigisannut inissiguk.


## Ajornartorsiutinik aaqqiineq (Troubleshooting)

Atassusiiffiup susoqartillugu tamarmik allattortarpai: Gladys UI-mit log-it misissukkit (imaluunniit `docker logs` host-imi) uunga `LOG_LEVEL=debug` paasissutissat tamakkiisut piniarlugit.
