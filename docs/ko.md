# Gladys용 Transitous Departures 연동 가이드

## 준비 사항:

Gladys Assistant > 버전 5.2

Transitous Departures 외부 연동 서비스

Gladys Assistant 설치 환경의 인터넷 연결

## 주요 기능:

Gladys Assistant를 위한 외부 연동 서비스를 제공합니다.
이 연동 서비스는 지정된 반경 내의 버스, 기차, 페리, 케이블카 등 다음 6개의 대중교통 출발 정보를 직관적이고 읽기 쉬운 위젯으로 자동 표시합니다.
이 모든 기능은 사용자의 집 주변으로 설정 가능한 검색 반경 내에서 작동합니다.

예시:

![리스본 – Transitous 연동 예시 보기](../test/lissabon.png)

작동 방식: 6개의 타일 각각에 대해 먼저 가장 가까운 정류장(가장 가까운 버스 정류장, 페리 선착장, 철도역 등)을 한 번씩 확인합니다.
그 후 해당 정류장에서 출발하는 다음 일정을 표시합니다.
즉, 설정한 검색 반경 내에 정류장이 하나만 있는 경우 해당 정류장의 다음 6개 출발 정보가 표시됩니다.
여러 정류장이 발견되면 가독성을 높이기 위해 색상 코드로 구분하여 표시됩니다.

## 설정 방법

1. Gladys Assistant를 통해 외부 연동 서비스를 설치하거나(권장), GitHub에 직접 액세스하여 Gladys Assistant에 설치합니다.

2. 설치 후 연동 서비스가 정상적으로 실행 중인지 확인합니다.
   
3. 대시보드를 열고 편집 모드(Edit Modus)로 들어간 후, 새 위젯을 추가합니다.
   이 연동 서비스 위젯을 선택해 주세요.
   
4. 대시보드에 위젯을 추가할 때 다음 정보가 필요합니다:
   
a.) 기준점이 될 사용자의 지리적 위치 좌표
 (또는 Gladys Assistant에 저장된 위치 선택)
 
b.) 검색 반경의 직경(미터 단위)

c.) 10분 단위로 설정 가능한 새로고침 간격

d.) https://transitous.org 에서 API 액세스를 위해 사용하는 고유 식별자.
이 식별자는 이메일 주소나 웹사이트 주소 등 고유한 값이어야 합니다.
이 정보는 연동 서비스의 설정 필드에만 저장되며, 연동 서비스 외부로 전송되거나 기록되지 않고 완전히 사용자 본인에게만 유지됩니다. Transitous.org는 IT 인프라의 부하를 관리하기 위해 이 식별자를 활용합니다.
데이터 제공업체의 기준을 고려하여 새로고침 간격을 설정해 주세요. 일반적으로 15분을 권장합니다.

5. 정보를 모두 입력한 후 저장하고, 위젯을 원하는 위치에 배치합니다.


## 문제 해결 (Troubleshooting)

본 연동 서비스는 모든 작업 내역을 로그로 기록합니다. 상세한 디버깅 정보가 필요한 경우, Gladys UI의 연동 로그(또는 호스트의 `docker logs`)에서 `LOG_LEVEL=debug` 설정을 적용하여 확인하시기 바랍니다.
